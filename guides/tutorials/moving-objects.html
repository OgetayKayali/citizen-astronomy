Set up the example / Step 04

Enter the telescope coordinates

Start here The Settings window is open. These coordinates come from the example FITS headers.

  1. Click the Setup tab. Scroll to Observing Site if the fields are below the visible area.
  2. Enter 31.5472 for Observing Latitude.
  3. Enter -99.3825 for Observing Longitude. The minus sign indicates west longitude.
  4. Click Save. For your own observing night, enter the site where those frames were taken.
What you should see

The settings dialog closes. CAst can now use the example site when checking whether a predicted object was above the horizon.

Load frames and predict objects / Step 10

Generate known-object predictions

Start here A folder is loaded through the File menu. Use the example telescope location and an internet connection.

  1. At the far right of the top row, open Frame and choose the entry beginning 1. and ending 0001_c.fits. Leave Group at All for these L / 120 s images.

What you should see

Rows appear in the object table. The first exposure started at 09:00:30 UTC on December 7, 2025. The app uses the FITS timestamp. In this run 50 predictions fell inside the frame. Catalogue updates can change the list.

Check a known object / Step 11

Locate 3I/ATLAS in the table

Start here Generate has finished for the first exposure.

  1. Click 3I/ATLAS in the Object column. Scroll within the table if needed.
  2. Click Inspector just below the table. Read Current measured offset and Current frame SNR. Offset is the distance in pixels between the prediction and the nearby peak. SNR tells you how strongly that peak stands out from the local background.
What you should see

The selected row says Comet and interstellar. The first practice frame gave an offset of 0.33 pixel and SNR 9.82. Check more than one exposure before attributing a peak to the comet.

Find it in the image →Compare a main-belt asteroid →Check positions across frames →Look for other movers → Browse all steps

Check a known object / Step 12

Inspect the main-belt asteroid (90) Antiope

Start here Generate has finished on the first exposure.

  1. Click (90) Antiope in the object table. Its Type is Asteroid and its Class is main-belt.
  2. Click Inspector. Compare Motion rate with the comet’s 158.41 arcseconds per hour. An arcsecond is a unit of angle on the sky.
What you should see

Antiope moves about 24.8 arcseconds per hour here. It shifts less than 3I/ATLAS between these short practice exposures. The image controls now follow the asteroid you selected.

Center this asteroid →Switch back to 3I/ATLAS →Compare predicted sky motions → Browse all steps

Check a known object / Step 14

Play the frames as a blink

Start here A folder with at least two images is loaded. Select an object row to follow it during playback.

  1. Use Track Object to choose your reference. Turn it on to keep the selected prediction centered. Turn it off to keep the registered stars fixed and see the object move.
  2. Click Blink. Wait for the first preload to finish. Watch several cycles, then click Blink again to pause. If a marker covers the pixels, turn off Target Marker.
What you should see

The Frame number advances during playback and stops when paused. The practice images share a star grid, so with tracking off the background stays almost fixed.

Blink between two example frames →Save the animation →Stack on the comet → Browse all steps

Check a known object / Step 15

Compare frame 1 with frame 5

Start here You can use the frame switch on this page immediately. To reproduce the view in CAst, center 3I/ATLAS, switch off Track Object and Target Marker, and zoom in over the comet.

  1. Use this page’s Frame 1 and Frame 5 controls to switch between captures. In CAst, use the marked Frame selector to make the same change.
  2. Watch the diffuse bright patch inside the outlined box. Compare its position with a nearby star outside the box. The zoom and sky position stay fixed between the two images.
What you should see

The comet shifts across the box, while nearby stars stay in approximately the same places. Try toggling several times to see the movement.

Measure the track / Step 18

Read the five frame measurements

Start here The Plots window is open for 3I/ATLAS.

  1. Click a row in the table to read a single exposure. Pred x/y gives the expected pixel position. Meas x/y gives the nearby measured peak. Scroll horizontally for Offset and SNR.
  2. Compare the plotted measured positions with the predicted path above the table. Check the offset plot for a sudden jump to a different source.
What you should see

Here all five frames have measurements and the offsets are approximately 0.3 to 1.1 pixels. Small offsets across several frames support the identification more strongly than a single close match.

Measure the track / Step 19

Stack the images on the comet

Start here The five-image folder is loaded with 3I/ATLAS selected. Close the plots window and stop Blink if needed.

  1. Click Synthetic Track in the top row. Use the default object-centered settings for this example. If you enabled advanced settings previously, keep the object-centered crop and the predicted motion.
  2. Wait for the preview. CAst shifts each exposure by the object’s predicted motion before combining them. Light from the moving target adds up in one place.
What you should see

The Synthetic Tracking preview opens with a zoomed image, a frame count and the stack measurement.

Read and save the stack → Browse all steps

Measure the track / Step 20

Check the stack and export it

Start here The Synthetic Tracking preview is open.

  1. Click Overlays to choose which marks to display. Compare Predicted center with Measured peak. Read the used-frame count and the offset above the image.
  2. To keep the stack, click Export Image…. Choose Raw FITS Files for the numerical stack or PNG Files for a rendered preview. Choose a destination, name the file, and click Save.
What you should see

The five-frame practice run used 5 of 5 frames, measured a stacked SNR of 6.95 and placed the peak 1.00 pixel from the predicted center. Different settings or frames can change these measurements.

Compare the individual frame positions →Search for other movers → Browse all steps

Search for other movers / Step 21

Start a search for additional movers

Start here Generate has finished for your folder. Use at least three solved frames for the default search. Let any blink preload finish.

  1. Click Discover in the workflow row. If CAst offers an earlier result, choose Run New Scan for a fresh search or Restore Last Result to review it.
  2. If the button is disabled, hover over it for the missing requirement. For a mixed folder, select a single filter/exposure group. The practice folder has only one group.
What you should see

For a new search, the Discover Pipeline dialog opens. Discover looks for sources whose positions change after the fixed star field is subtracted.

Set up the practice scan →Read an existing result → Browse all steps

Search for other movers / Step 22

Run a quick practice scan

Start here The Discover Pipeline dialog is open for the five-frame practice folder.

  1. Set Preset to Fast scan.
  2. Set Alignment to Already aligned. These example exposures were registered to the same star grid. For a different sequence with drifting stars, choose Align first.
  3. Set Working Binning to 4x4. This combines neighboring pixels for a smaller working image.
  4. Clear If no candidates are found, retry automatically with the detailed full-resolution search for this short practice scan.
  5. Click Run Discover. Leave the progress window open until the batch finishes. If you enabled a final synthetic sweep separately, choose No at its prompt to inspect residual-only results.
What you should see

The Discover Results window summarizes known objects recovered and additional candidate tracks. Strong binning speeds the exercise and can hide faint or slow movers.

Read the results → Browse all steps

Search for other movers / Step 23

Read the discovery results

Start here A Discover scan has completed, or you restored a previous scan for the same group.

  1. Click Known Recovered to see catalogue objects the independent motion search linked across frames. The adjacent Known Missed tab lists predictions it did not recover.
  2. Click Potential Discoveries to review stronger unmatched tracks. Use the number in parentheses to see whether there are any rows to inspect.
  3. Click Borderline Review to see less consistent tracks. Follow up any interesting row by checking its position in the original images across several frames.
What you should see

In this five-frame, 4×4-binned residual scan, zero tracks linked. The 50 catalogue predictions appear under Known Missed. The visible-limit benchmark was omitted in this capture, so Visible Limit reads Not estimated. The separate first-frame match and comet stack still show 3I/ATLAS.

Save the run summary →Check a track in the original images →Review the scan settings → Browse all steps

Save an image or animation / Step 27

Export a blink animation

Start here A sequence of at least two frames is loaded. Choose the framing, target marker and tracking state you want to share.

  1. Click Export on the image toolbar.
  2. Choose Blink…. Select Animated GIF Files for a looping image or MP4 Video Files for a video. Pick a folder, enter a filename such as 3I-ATLAS-blink.gif, then click Save.
  3. Wait for export to finish. Open the saved file and check that the star field or the tracked target moves as you intended.
What you should see

The five-frame example exported as an animated GIF. A still frame can be saved separately from the same menu.
