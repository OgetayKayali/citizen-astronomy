Open M46 and build the map / Step 01

Enter Distance Map

Start here Start Citizen Astronomy (CAst). Have your M46.xisf file available.

  1. In the launcher, scroll to Explore, Visualize & Process. Click Distance Map (1). If a different mode is open, you can choose Mode → Distance Map from the top menu.
What you should see

The workspace opens with Open at the left end of its toolbar. The empty panels are labeled Field Image, 3D Distance Map, Catalog Stars, and Work Log.

Open the image picker →I already opened my image → Browse all steps

Open M46 and build the map / Step 02

Open the image picker

Start here The Distance Map workspace is visible.

  1. Click Open (1) at the left end of the mode toolbar. You can also use File → Open File.
What you should see

A file picker titled Select source image for Distance Map opens. You will choose a single image.

Choose M46.xisf → Browse all steps

Open M46 and build the map / Step 03

Choose the M46 image

Start here The image picker is open.

  1. Open the extracted M46 folder and select M46.xisf, or type its path in File name (1).
  2. Click Open (2). Leave the app running while it reads the image coordinates and looks for Gaia stars in that part of the sky.
What you should see

The M46 photograph appears in Field Image. The toolbar may briefly show Building.... A previously cached catalog can make this step finish quickly.

Check the build →Set the depth for M46 → Browse all steps

Open M46 and build the map / Step 04

Check that Gaia stars were drawn

Start here You have chosen M46.xisf.

  1. Find Work Log under the catalog table on the right (1). Scroll inside it to the lines beginning Distance Map built from M46.xisf and Stars drawn in the 3D map.
  2. Look at the Distance Limit value in the toolbar. The 500 pc starting limit shows nearby foreground stars. Increase this limit to explore the cluster in depth.
What you should see

This example drew 107 stars at 500 pc using the saved Gaia DR3 field catalog for this exact image. A parsec (pc) is about 3.26 light-years. Your count can vary with saved settings, catalog coverage and query limits.

Include more distant stars →Explore the current map →Understand the other catalog limits → Browse all steps

Open M46 and build the map / Step 05

Include the cluster in the depth range

Start here A build has finished. Use the M46 image for this example.

  1. In Distance Limit (1), select the number, enter 3000, and press Enter. For this example leave Mag Limit at 17.0, Max Stars at 500, and Min SNR at 5.0.
  2. Click Apply (2). Wait until the controls become available again and the Work Log reports the new number drawn.
What you should see

The new range includes stars out to 3,000 pc. In the example, 1,351 catalog stars passed the footprint, distance and quality filters, and CAst drew the brightest 500 of them. Those 500 include foreground and background stars as well as cluster candidates.

See distances derived from parallax →Search for stars moving together →Place the photograph in the map → Browse all steps

Open M46 and build the map / Step 06

Change which catalog stars enter the map

Start here An image is loaded. These settings change the sample for every later task.

  1. Change Mag Limit (1) if you want a different brightness cutoff. A smaller number keeps brighter stars. Max Stars (2) caps the number drawn after filtering.
  2. Use Min SNR (3) to set the minimum ratio of measured parallax to its error. Increasing it asks for more precise parallaxes. Keep 17.0, 500, and 5.0 to match this tutorial.
  3. Click Apply (4). Read the new counts in Work Log before running another cluster search.
What you should see

The star map and table update to the new selection. If too few stars remain, undo the last change and click Apply again.

Choose the depth range →Read the catalog measurements →Find a group in this sample → Browse all steps

Read and navigate the 3D field / Step 07

Switch between measured and modeled depth

Start here A map is drawn. The example starts with Model Cluster Depth checked.

  1. If Model Cluster Depth (1) is checked, click it once to clear the check. Leave it clear when comparing distances derived directly from parallax.
  2. To try the display model later, turn it back on. CAst redistributes likely members within a compact model around the group distance.
What you should see

With the box clear, the Distance (pc) column uses 1,000 divided by parallax in milliarcseconds. When the model is enabled, candidate positions and their displayed distances can change. Their Gaia parallaxes stay the same.

Read one catalog row →Choose a camera angle →Search for a moving group → Browse all steps

Read and navigate the 3D field / Step 08

Choose a view and declutter it

Start here Build a map. These controls are on its toolbar.

  1. Open View (1) and choose Side View. Try Top-Down for a different direction or Field Center for a closer preset.
  2. Clear Labels (2) if the star names cover the points. Leave labels off for the example screenshots.
  3. After moving the camera, click Reset View (3) to return to the selected preset.
What you should see

Seen from the side, this narrow patch of sky looks like a long, thin group of points. Stars close together in the photograph can be widely separated along this line.

Rotate or zoom with the mouse →Add a depth scale →Read a numerical distance → Browse all steps

Read and navigate the 3D field / Step 09

Rotate and zoom the point cloud

Start here A 3D view is on screen. Use the middle panel titled 3D Distance Map.

  1. Place the mouse over the marked patch in the 3D panel (1). Hold the left mouse button and drag sideways to orbit, then release.
  2. Roll the wheel up to zoom in or down to zoom out. To shift the view without rotating it, hold the middle mouse button and drag.
What you should see

The point cloud changes orientation or size while the photograph and table keep their positions. If the cloud leaves the screen, Reset View restores your selected camera preset.

Add a scale in parsecs →Insert the actual image →Save this camera view → Browse all steps

Read and navigate the 3D field / Step 10

Read the distance to one star

Start here A map is drawn. For a distance derived directly from parallax, clear Model Cluster Depth.

  1. In Catalog Stars at the right, click a row to keep your place. Read the entries under Parallax and Distance (pc) in that same row (1).
  2. Read Name to identify the catalog source and G mag for its Gaia brightness. Smaller magnitude numbers indicate brighter stars.
What you should see

The row stays selected while you read across it. A parallax of 1 milliarcsecond corresponds to 1,000 pc on this scale. Selecting a row leaves the 3D camera in place.

Show how uncertain a distance is →Identify candidate group members →Adjust the catalog quality cut → Browse all steps

Read and navigate the 3D field / Step 11

Add a scale along the line of sight

Start here The 3D field is visible. Use Side View to see depth spread across the screen.

  1. Click Distance Ruler (1) to check it. Follow the scale along the direction from the observer through the star field.
  2. Zoom toward the points with the mouse wheel if the tick marks are crowded. Click the box again to remove the scale.
What you should see

The 3D panel gains tick marks and distances in parsecs along the viewing direction. The same stars remain in the table.

Add parallax uncertainty →Compare the scale with the image plane →Save the scaled view → Browse all steps

Read and navigate the 3D field / Step 12

Show uncertainty in stellar depth

Start here A map is drawn. Choose Side View to see differences along the line of sight.

  1. Check Parallax Uncertainty (1). Look along the points in the 3D map for the line segments marking their distance intervals.
  2. If the stars crowd together, zoom in. Clear Parallax Uncertainty when you want to see only the points again.
What you should see

Longer segments indicate a wider range of plausible depth from parallax error. The Work Log reports how many intervals CAst drew. Increasing Min SNR gives a way to examine only more precisely measured stars.

Set the minimum parallax quality →Inspect a catalog row →Add the scale → Browse all steps

Find and inspect a moving group / Step 13

Find stars that move together

Start here Build the M46 map out to 3,000 pc. For this example, clear Model Cluster Depth and use the default cluster search preset.

  1. Click Find Cluster (1). CAst searches the drawn stars for a group with similar proper motions and, when available, similar parallaxes.
  2. Read the Highlighted … likely cluster member(s) line in Work Log. If you want to change the search first, click Advanced... (2) and use the preset branch below.
What you should see

With the example settings and cached catalog, the default search highlighted 145 candidates. The button changes to Find All, and matching catalog rows turn gold. The shared motion makes these stars candidates for membership in the cluster.

Show only those candidates →Choose a detection preset →Locate the candidates in the photograph →Check the globular-cluster overlay → Browse all steps

Find and inspect a moving group / Step 14

Isolate the candidate stars

Start here Complete a Find Cluster search so the button reads Find All.

  1. Check Only Group (1). To inspect a candidate row or locate it in the photograph, leave this box checked and choose one of those tasks below.
  2. To see the surrounding stars while keeping the candidates highlighted, clear Only Group. When you want to clear the highlights too, click Find All (2).
What you should see

With Only Group checked, the example table contains the 145 highlighted stars. After Find All, the map returns to the full sample and the search button reads Find Cluster again.

Read a highlighted member row →Inspect the circles on the photograph →Change the search → Browse all steps

Find and inspect a moving group / Step 15

Read a highlighted member row

Start here Find a group, then check Only Group.

  1. Scroll through Catalog Stars and click a highlighted row (1). Read across for the candidate’s name, brightness, parallax and distance.
  2. To see its parallax-derived distance, check that Model Cluster Depth is clear.
What you should see

Only candidate rows appear while the group filter is active. Their distances still span a range because parallax measurements have uncertainties.

Inspect the depth intervals →View the candidate markers →Compare measured and modeled depth →Explore candidate motions in HR Diagram → Browse all steps

Find and inspect a moving group / Step 16

Locate candidates in the original M46 photograph

Start here Complete Find Cluster. Keep the group selected.

  1. Move the pointer over the left Field Image panel (1). Scroll up to magnify the photograph and left-drag to bring a region of interest into view.
  2. Look for the colored circles around candidate stars. Use the central 3D panel when you want to rotate the depth map.
What you should see

The source photograph keeps its sky orientation as you pan and zoom. Circles identify the stars highlighted by the group search.

Read the candidate table →Place this photograph in 3D →Return to the full sample → Browse all steps

Find and inspect a moving group / Step 17

Choose a tighter or looser search

Start here A map is drawn. If Find All is showing, click it to clear the previous search. Then click Advanced... beside Find Cluster.

  1. Open Preset (1). Choose Tight for a more concentrated group, Loose for a broader proper-motion search, or Default to reproduce the example.
  2. Check Turn on Only Group automatically after detection (2) if you want the map to isolate candidates immediately. Click OK (3), then Find Cluster on the toolbar.
What you should see

The Work Log names the chosen preset. A different preset can select a different candidate set. If nothing is identified, try Default or Loose and make sure the distance range includes the cluster.

Run the chosen search →Adjust individual search settings →Check the distance cutoff → Browse all steps

Find and inspect a moving group / Step 18

Adjust individual cluster settings

Start here Open Advanced.... Click Show Expert Controls if the extra fields are folded.

  1. Use Strictness (1) to adjust how closely the stars must group in the search. A lower value tightens the selection.
  2. Open Parallax (2) to choose Auto, Require parallax, or Proper motion only. Changing an expert setting switches Preset to Custom.
  3. Click OK (3) to keep the settings and run Find Cluster again. To return to the original settings, reopen the dialog and choose Default.
What you should see

The dialog records a Custom preset for your changes. Each new search uses the same stars until you change a catalog limit and click Apply.

Run the custom search →Restore a built-in preset → Browse all steps

Find and inspect a moving group / Step 19

Check for a cataloged globular cluster

Start here A map is drawn. This optional overlay is useful when exploring a globular-cluster field.

  1. Click Catalog Sphere (1). Read Work Log to see whether CAst matched the image to a globular cluster in its bundled list.
  2. Clear Catalog Sphere to turn the overlay off. For M46, use Find Cluster to search the actual stars for a moving group.
What you should see

M46 is an open cluster. For this image the log reports that no named globular cluster matched, so there is no sphere to draw. A matched globular field can show a wireframe sphere at the catalog distance.

Search the open-cluster field →Inspect the depth model → Browse all steps

Move the photograph through the map / Step 20

Place the M46 photograph inside the 3D map

Start here Build the map. If the group filter is active, use Find All to return to the full map.

  1. Click Tomography (1). The View selector changes to Tomography Face-On.
  2. Move the pointer over the middle of the 3D panel and scroll up until the image plane is easy to see. A wide depth range can make the plane look very small at first. Use the two screenshot buttons here to compare the starting and enlarged views.
What you should see

Your M46 image appears as a translucent plane perpendicular to the line of sight. It starts partway through the stars’ depth range. The Work Log gives its starting distance in parsecs.

Slide the plane in depth →Save the current slice →Choose a different viewpoint → Browse all steps

Move the photograph through the map / Step 21

Move the image plane nearer or farther

Start here Turn on Tomography. Choose Orbit Overview from View so you can see the direction of depth.

  1. Place the pointer over the marked region of the 3D panel (1). Hold Ctrl and the left mouse button, then drag up to move the slice farther away or down to bring it closer.
  2. Release the mouse and Ctrl. To inspect the plane head-on again, choose Tomography Face-On from View. Click Tomography again to remove it.
What you should see

The photograph changes depth within the same star map. The slice is a movable reference plane. Its position does not assign a common distance to all the stars in the image.

Save this view →Read the scale along the slice →Return to the face-on image → Browse all steps

Save a figure / Step 23

Choose the filename and format

Start here The Save Distance Map Image picker is open.

  1. Choose a folder you can write to. In File name (1), enter M46_3D_example.png or another new name. Leave PNG Files selected for this example.
  2. Click Save (2). Locate that file in your chosen folder and open it to inspect the result.
What you should see

The saved image contains the 3D scene from your selected camera. The Work Log reports the saved path. You can return to CAst, change the view and save a second figure with a different name.
