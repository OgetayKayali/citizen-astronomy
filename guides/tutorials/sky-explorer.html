Open a photograph or a survey / Step 01

Enter Sky Explorer

Start here Start Citizen Astronomy (CAst).

  1. On the mode launcher, find Explore, Visualize & Process and click Sky Explorer (1). From another workspace, you can also use Mode → Sky Explorer.
What you should see

The toolbar offers Image for a picture on your computer and Survey for a field downloaded from a public sky survey.

Use a photograph →Start with a public survey → Browse all steps

Open a photograph or a survey / Step 02

Open the image picker

Start here Enter Sky Explorer. Have one image ready.

  1. Click Image (1) at the upper left. For this example, use the single file M46.xisf.
  2. If you already have an image open, click Replace to start a new field. Choose Comparison if you want to keep the first image on screen.
What you should see

A file picker opens. A plate-solved image already contains the map between its pixels and coordinates on the sky.

Select the M46 file →Use a public survey instead → Browse all steps

Open a photograph or a survey / Step 03

Load the M46 photograph

Start here The image picker is open.

  1. Navigate to the folder containing M46.xisf and select that file. You can also type its full path in File name (1).
  2. Click Open (2) and wait for the stars to appear in the image pane. If you are using your own exposure, select its filename instead.
What you should see

The field fills the right side of the workspace. For M46 you should see a crowded patch of stars near the middle. The Explore button is now available.

Set up the bright-star example →Adjust the image display →Search part of the photograph →Add a second image → Browse all steps

Open a photograph or a survey / Step 04

Start without a local image

Start here Enter Sky Explorer with an empty workspace and an internet connection.

  1. Click Survey (1), next to Image. If a local image is already open, this button adds a survey as a comparison over that image.
What you should see

A survey picker opens. With an empty workspace, the downloaded sky field becomes your primary image.

Choose the survey →Switch to a local image → Browse all steps

Open a photograph or a survey / Step 05

Choose a public sky survey

Start here The survey picker is open.

  1. Click the survey list (1). Choose DSS2 Blue to follow the selection pictured, or choose another survey with coverage of your field.
  2. Read the starting coordinates and field size below the list. Click OK (2). Wait for the center preview, then the sharper tiles.
What you should see

At the default coordinates the field is centered near the Trifid Nebula. After the tiles appear, you can run a catalog search on this field. Its objects and counts will differ from the M46 example.

Choose catalog sources →Adjust the survey display →Load M46 instead → Browse all steps

Mark the bright Gaia stars / Step 06

Open the catalog settings

Start here Load M46 or open a survey field. To reproduce the count shown in this guide, use M46 and the entire image.

  1. Click Settings (1) in the main menu bar, then Open Settings (2).
What you should see

The settings window opens with tabs for the different workspaces. The next two steps set a bright-star limit and choose Gaia as the catalog for this example.

Set the brightness limit →Choose the catalog sources → Browse all steps

Mark the bright Gaia stars / Step 07

Set a bright-star limit

Start here Open Settings.

  1. Select the Sky Explorer tab (1), then its General tab (2).
  2. In Gaia Max Mag (3), enter 9.5. Leave Gaia Hard Cap unchecked for this example.
What you should see

The field reads 9.5 mag. Smaller Gaia magnitudes mean brighter stars, so this limit keeps the first set of labels manageable.

Enable Gaia and save the settings → Browse all steps

Mark the bright Gaia stars / Step 08

Choose the Gaia catalog

Start here Open Settings → Open Settings → Sky Explorer → General. For the pictured run, set Gaia Max Mag to 9.5.

  1. Scroll to Catalog Sources (1). To reproduce this search, tick Gaia DR3 Stars and clear the other five sources. If you want to return to a previous setup, note its checked boxes first.
  2. Click Save (2). When exploring another class later, return here to enable its matching source.
What you should see

The settings window closes. Gaia Data Release 3 is the available source for this run. You will next select which kind of object to draw.

Choose the object-type list → Browse all steps

Mark the bright Gaia stars / Step 09

Show the Advanced object list

Start here An image or survey is loaded. For the example, use the Gaia catalog settings.

  1. Find the mode button immediately right of Explore (1). Click it until its label reads Advanced. From the initial Simple list, one click is enough.
What you should see

The table now contains human-readable classes including Star. Simple lists common deep-sky classes. Continuing to cycle the same button opens Scientific for detailed classifications and Catalog for catalog names.

Start with an empty selection → Browse all steps

Mark the bright Gaia stars / Step 10

Clear the previous selection

Start here The Advanced object list is visible.

  1. If Unselect All (1) is showing, click it once. If the button reads Select All and any rows are checked, click it to select every row and then click Unselect All.
  2. If all rows are already empty, leave them empty and proceed to Star.
What you should see

The object checkboxes are empty and the button reads Select All.

Select the Star row → Browse all steps

Mark the bright Gaia stars / Step 11

Select stars as the search target

Start here The Advanced selection is empty.

  1. Scroll within the object-type table to the Stars group. Under Object Type, tick Star (1).
  2. Leave the other rows unchecked. The group heading can switch several types together.
What you should see

A check appears beside the Star row. Combined with the Gaia catalog setting, this asks for Gaia field stars.

Search the entire field →Restrict the search area → Browse all steps

Mark the bright Gaia stars / Step 12

Run the catalog search

Start here A field is loaded and at least one compatible catalog source and object type are enabled. For the M46 count, use Star with no region selected.

  1. Click Explore (1). Leave the field open while CAst checks its coordinates and looks up the selected sources.
  2. The button reads Terminate while the search runs. Click it only if you want to stop the search.
What you should see

The results table fills and small markers appear on the image. With the saved M46 Gaia catalog and the 9.5 limit, 22 stars landed inside the image. A different field, limit, or selected region gives a different count.

Check how many stars were found →Inspect one of the stars →Repeat the search in one region → Browse all steps

Inspect a result and the photograph / Step 13

Read the search summary

Start here Run Explore.

  1. Click Work Log (1) below the results table. Read the last entry for the field size and the number prepared for display.
  2. In this run the cached search area contained 34 stars at G ≤ 9.5. The last line reports 22 in the rectangular M46 image.
What you should see

The log shows the source filename, selected object type, catalog and final count. A first online lookup can show download messages in place of the cached-catalog line.

Select a Gaia star →Change the brightness limit → Browse all steps

Inspect a result and the photograph / Step 14

Select a star in the results

Start here A completed search has returned at least one star.

  1. In the results table below the object-type list, click once on a numeric name under Stars (1). Click the group header first if its rows are collapsed.
  2. The example follows Gaia source 3029166186781118336. Select any returned star in your own image.
What you should see

The selected row turns amber and the corresponding position is highlighted in the photograph.

Read its coordinates and brightness →Center the photograph on it → Browse all steps

Inspect a result and the photograph / Step 15

Read the selected star’s measurements

Start here Select a result row.

  1. Click Inspector (1), beside Work Log. Match Name to the selected row.
  2. Read RA and Dec for its sky position, then Magnitude for its catalog brightness. Scroll down to see additional catalog measurements.
What you should see

The example star is at RA 115.096700°, Dec −15.264043°, with Gaia magnitude 4.39. The pixel position identifies where the catalog coordinates fall in this image.

Center this star →Measure a separation →Inspect a different star → Browse all steps

Inspect a result and the photograph / Step 16

Center the image on your selection

Start here A star is selected in the results table.

  1. Click Center Object (1) near the right end of the toolbar.
  2. Look in the middle of the image pane for the highlighted catalog marker.
What you should see

The view pans to the selected position. Its Gaia name and catalog measurements stay attached to the same star.

Read the centered star’s details →Change the display stretch →Save an annotated image → Browse all steps

Inspect a result and the photograph / Step 17

Open the display controls

Start here Load a local image to follow the M46 example, or open a survey field.

  1. Click Display (1) on the top toolbar, just beyond the annotation tools.
What you should see

The menu contains separate controls for the primary image and a comparison layer when one is loaded.

Choose an image stretch →Compare two local images → Browse all steps

Inspect a result and the photograph / Step 18

Choose an image stretch

Start here Open the Display menu. A stretch maps the image’s brightness values to your screen.

  1. Under Image, open Stretch (1). Try STF Bright to bring up faint structure. Return to STF to reproduce the example view.
  2. To return the image display controls to their defaults, click Reset (2). Click outside the menu to close it.
What you should see

The appearance of the field changes. The stars in the catalog table keep their original magnitudes and coordinates.

Choose a region →Measure between two points →Save the result → Browse all steps

Work in one region or compare images / Step 19

Search only a region of the image

Start here A source is loaded and a search target is selected.

  1. Click the dashed ROI rectangle (1), immediately after the text tool. ROI means region of interest.
  2. Press and hold the left mouse button on the image, drag to the opposite corner of the area you want to search (2), then release. Click Explore to search that area.
What you should see

Inspect the results inside the dashed green rectangle. On a solved image its angular width and height appear near the top-left corner when that readout is enabled. When you want to search the full field again, click ROI to remove the rectangle and click Explore.

Run the selected search →Measure a separation instead → Browse all steps

Work in one region or compare images / Step 20

Measure the separation between two positions

Start here A source image is visible. Clear an active ROI first if you want a clear view.

  1. Click the diagonal Ruler tool (1) in the drawing toolbar.
  2. Press the left mouse button on the first position, drag to the second, then release (2). Read the label beside the line.
What you should see

The ruler links your two positions. On this solved image the label gives an angular separation in arcminutes, marked with a prime (′). Your result depends on the points you chose.

Save the image with the ruler →Draw a search region →Compare a second image → Browse all steps

Work in one region or compare images / Step 21

Add a second image for comparison

Start here Open a primary image. Have a second view of the same field ready. The example compares the M46 color frame with its red channel saved as a monochrome FITS file.

  1. Click Image again. In Image already loaded, click Comparison (1) to keep the original in the viewer.
  2. Select your second file in the picker and click Open. For a pixel-by-pixel comparison, use two images registered to the same field.
What you should see

A vertical divider appears over the two images. Replace in the source prompt starts over with a different primary field.

Drag the comparison divider →Start with another primary image → Browse all steps

Work in one region or compare images / Step 22

Move the divider across the same stars

Start here A comparison image is visible.

  1. Place the pointer on the small white handle in the middle of the vertical divider (1). Hold the left mouse button and drag it horizontally.
  2. In this example, drag right to reveal more of the original color field. Drag left to show more of the monochrome red-channel view. Compare the same bright star on both sides.
What you should see

The same stars stay in place while the color boundary moves. Switch between the two screenshots below the instructions to see both handle positions.

Adjust the display →Save the annotated primary image → Browse all steps

Save the annotated field / Step 23

Choose the annotated image export

Start here Open a local image and leave the catalog markers or ruler you want to include on screen.

  1. Click Export (1) at the right end of the toolbar, then Image… (2).
  2. If you are working with a survey and want that layer instead, choose Survey… when it is available.
What you should see

A save dialog opens for the annotated image. The exported image uses the original image resolution.

Choose the filename →Add a measurement first → Browse all steps

Save the annotated field / Step 24

Name the file and save it

Start here Choose Export → Image….

  1. Choose the destination folder in the file picker. Enter a new filename such as M46-study.png in File name (1).
  2. Keep PNG Files selected and click Save (2). Open the saved PNG from that folder to inspect the markers at full resolution.
What you should see

The saved PNG contains the photographed field and its visible annotations. The M46 example exports at 2742 × 2460 pixels.
