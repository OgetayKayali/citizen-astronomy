Record your first eclipse / Step 01

Open Binary Light Lab

Start here Start Citizen Astronomy (CAst).

  1. Scroll to Simulations on the mode launcher. Click Binary Light Lab (1). If another workspace is open, choose Mode → Binary Light Lab from its top menu.
What you should see

The left panel shows a preset menu and Play. The star view and the LIVE LIGHT CURVE graph appear to the right. At the opening phase one star can cover part of the other.

Choose the eclipse example →Explore another kind of star →Open a saved system → Browse all steps

Record your first eclipse / Step 02

Choose the Algol-like binary

Start here Open Binary Light Lab. If a previous model is playing, click Pause first.

  1. Open the preset menu below Binary Light Lab (1) and select Algol-like / unequal temperatures. If that name is already showing, leave it selected.
  2. For a fresh run of the current example, click Restart below the menu. Export any recording you want to keep before restarting.
What you should see

The description identifies a hot primary star and a cooler companion. At phase zero the companion partly blocks the hotter star in this example.

Start recording →Change the viewing angle →Compare the star temperatures →Adjust the glow around the stars → Browse all steps

Record your first eclipse / Step 03

Play, record, and pause

Start here Open a periodic system in the lab. The screenshots use the Algol-like example. If you just loaded your own binary, you can record it the same way.

  1. Click Play (1). The stars start moving, and the counter beside the graph (2) begins counting samples. Each sample measures the two stars’ combined light.
  2. Watch the gold line above Phase / one cycle travel across the graph. Let it reach the right edge and wrap to the left to record a full orbit.
  3. Click Pause in the same spot (1). To keep adding samples from this phase, click Play again.
What you should see

The cyan trace dips when one star crosses in front of the other. Pausing holds the stars, the gold cursor and the samples in place.

Compare your trace with the prediction →Jump to a phase →Save recorded samples → Browse all steps

Record your first eclipse / Step 04

Read the two eclipse depths

Start here Use the Algol-like example. You can reveal the prediction even before recording any samples.

  1. Select Show prediction (1) above the graph. Choose Relative flux in the menu beside it if another scale is showing.
  2. Read the gray curve from left to right (2). Phase 0 and phase 1 are the same point in consecutive orbits, so the deep dip at the two ends is one eclipse. Find the shallower dip near phase 0.5.
What you should see

Relative flux near 1 means you see the combined, uneclipsed light. In this example, blocking part of the hotter star removes more light than hiding the cooler star. Cyan marks show the phases you have recorded.

Make the stars equally hot →Make the eclipses disappear →Read differential magnitude → Browse all steps

Record your first eclipse / Step 05

Jump to a particular phase

Start here Use the Algol-like example. Export your samples first if you want to keep them. Seeking starts a new recording.

  1. Double-click the number beside Seek phase (1), type 0.250, and press Enter. Phase is the fraction of one orbit, so this jumps a quarter of the way around.
  2. To return to the starting phase, click Restart (2). Use Play when you are ready to record at the new position.
What you should see

Seeking pauses playback, moves the cursor and clears the sample count. At phase 0.250 the two stellar disks are separated in this example.

Record from here →Read the predicted curve → Browse all steps

Change the stars or the view / Step 06

Turn an eclipse on and off

Start here Choose the Algol-like example, pause playback, and turn on Show prediction. Model changes clear existing samples.

  1. Click Model (1). Double-click Inclination / deg (2), type 90, and press Enter. Look for the dips in the predicted curve (3). At this angle the orbit is edge-on.
  2. Replace 90 with 0 and press Enter. The orbit is now face-on. Switch between the two screenshots to compare the graph at the same phase.
What you should see

At 90° the stars can pass across each other along your line of sight. At 0° their disks stay separated, and the predicted flux stays at 1 across the orbit.

Change which star supplies the light →Restore the example →Export the ideal curve → Browse all steps

Change the stars or the view / Step 07

Make the eclipse depths more alike

Start here Choose the Algol-like example and turn on Show prediction. Recordings start over when you edit a star.

  1. Click Stars (1). Under PRIMARY / A, double-click Temperature / K (2). Replace 10000 with 4800 and press Enter. The primary now has the same temperature as the secondary.
  2. Compare the dips in the predicted curve (3) with the original unequal-temperature example. Read the depth of each dip relative to the level outside eclipse.
What you should see

The stars now have more similar surface brightnesses. Covering a portion of either star removes a more similar amount of light, so the two eclipses are closer in depth.

Try a different viewing angle →Change the observed wavelength →Save this star system → Browse all steps

Change the stars or the view / Step 08

Adjust the visible stellar glow

Start here Open the lab and pause at a phase where the two stars are separated. For the Algol-like model, try phase 0.250.

  1. Click Look (1). Double-click Stellar glow (2), enter 0, and press Enter. Look at the light outside the edge of each disk.
  2. Enter 1 in the same field to restore the default glow.
What you should see

Zero removes the soft halo from the rendered stars. The graph and sample count stay at their paused values while you change the display.

Choose another orbital phase →Resume recording → Browse all steps

Observe the light / Step 09

Compare red and blue light

Start here Select the Algol-like example, pause, and turn on Show prediction. Export any samples you want to keep before changing the band.

  1. Click Observe (1). Open the band menu (2), choose Blue / 390–490 nm, and look at both eclipse depths.
  2. Use the same menu to choose Red / 600–750 nm. Compare each dip with the uneclipsed part of its own curve.
What you should see

The cooler companion contributes a larger share of the light in the red band. In this example its eclipse makes a more pronounced secondary dip in red. Changing bands starts a new set of samples.

Add scatter to the measurements →Switch to a magnitude scale →Export a model in this band → Browse all steps

Observe the light / Step 10

Add scatter to a recording

Start here Select the Algol-like example. In Observe, choose the blue band and turn on Show prediction.

  1. Find Noise / ppm in Observe. Double-click its number (1), type 5000, and press Enter. This adds simulated measurement noise of 5,000 parts per million, or 0.5% of the reference flux.
  2. Click Play, let samples build up, then click Pause. Inspect the cyan points around the smooth prediction (2).
What you should see

Individual recorded measurements scatter above and below the ideal curve. The gray prediction keeps its original shape. Setting noise back to zero starts a fresh recording.

Export these samples →Read them as magnitudes → Browse all steps

Observe the light / Step 11

Read the curve in magnitudes

Start here Start with a prediction or recorded samples.

  1. Open the units menu above the graph (1) and choose Differential mag. Read the numerical scale at the left (2).
  2. Compare an eclipse with the level outside it. With the default Comparison flux of 1, the uneclipsed Algol-like pair is near zero differential magnitude.
What you should see

As the binary fades, its magnitude difference increases. Larger numbers appear lower on this graph, so eclipses still dip downward. Switch the menu to Relative flux to return.

Read relative flux →Save the measurements → Browse all steps

Explore the stellar library / Step 12

Load a different type of star system

Start here Open Binary Light Lab. Save a custom system or recording you want to keep before selecting another example.

  1. Click Library (1). Each Load button names an example, with a short description underneath. Scroll inside the left panel to see more.
  2. Click Load EB · Beta Lyrae (2) to try an eclipsing pair whose surfaces are stretched by gravity.
What you should see

The preset menu switches to EB · Beta Lyrae. The workspace loads the new stars and starts a fresh set of observations.

Inspect the stretched stars →Try playback →Return to the detached pair → Browse all steps

Explore the stellar library / Step 13

Inspect the Beta Lyrae model

Start here Load EB · Beta Lyrae from Library. Check Show prediction above the graph to display the full curve.

  1. Check the preset name above the controls (1) and click Model (2). Scroll down the controls to find the A polar radius / Roche pole and B polar radius / Roche pole fields. They set how fully each star fills the region around it bounded by its Roche lobe.
  2. Click Play and watch the shape each star presents as it turns. Compare the gently changing light outside eclipse with the flat portions of the detached pair’s curve.
What you should see

The stars have distorted shapes. The combined brightness can change between eclipses as their projected areas change. This model assumes a circular orbit with synchronized stellar rotation.

Try another family →Keep the system →Export the ideal curve → Browse all steps

Export curves or keep a system / Step 14

Export the ideal model curve

Start here Choose any valid system. You can export the model before playback.

  1. Click Observe. Scroll down inside the left panel to the file buttons. Click Export model CSV… (1).
  2. Choose the folder where you want the file. Enter a new name ending in .csv, such as algol-model.csv, and click Save.
What you should see

The CSV contains model settings and 1,001 points. For the detached binary, the rows cover phase 0 to 1, with time in days, relative flux and magnitude change. Open the CSV in a spreadsheet to inspect the numbers.

Export the recorded points as well →Keep an editable system → Browse all steps

Export curves or keep a system / Step 15

Export the recorded samples

Start here Record a few samples and pause. You can include simulated noise.

  1. Click Observe and scroll down inside the left panel. Look at the sample counter (2) above the graph. If it reads zero, click Play briefly and then Pause.
  2. Click Export observations… (1).
What you should see

The Export model and observations file dialog opens. You choose one name for the ideal model, and CAst derives a second filename for the measurements.

Choose the name and save both files →Save just the ideal model → Browse all steps

Export curves or keep a system / Step 16

Name the two CSV files

Start here Open Export observations….

  1. Choose a folder in the dialog, click File name (1), and enter my-eclipse.csv. Pick an unused base name to keep an earlier pair of exports.
  2. Click Save (2). Open the chosen folder to find the two files.
What you should see

my-eclipse.csv contains the ideal curve. my-eclipse-observed.csv contains your recorded points. For an eclipsing binary, compare ideal_flux with measured_flux on a row, and use phase to locate that point in the orbit.

Change the simulated noise →Keep an editable copy of the system → Browse all steps

Export curves or keep a system / Step 17

Save an editable star system

Start here Choose or edit the system you want to revisit. Export its recorded points separately if you want to keep those measurements.

  1. Click Observe and scroll down the controls on the left. Click Save system… (1).
What you should see

The Save system dialog opens for a CAst stellar model file. This file keeps the system and observing parameters for another session.

Name the system file →Reopen an earlier system → Browse all steps

Export curves or keep a system / Step 20

Choose the saved system

Start here Open Load system… and browse to the folder that contains the saved file.

  1. Click the file, or enter its name in File name (1). The example uses my-binary.starlab.
  2. Click Open (2).
What you should see

The description in the lab begins with Loaded. The controls now show the saved settings. Click Play to make a new recording from them.
