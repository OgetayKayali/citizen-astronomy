Open the M46 image / Step 01

Enter HR Diagram mode

Start here Start Citizen Astronomy (CAst).

  1. Find HR Diagram on the mode launcher and click its card (1). From an open workspace you can also choose Mode → HR Diagram.
What you should see

A reminder lists the image and catalog requirements. If you previously dismissed it, the workspace opens directly.

Check the image requirements →I already see the workspace → Browse all steps

Open the M46 image / Step 02

Check what the diagram needs

Start here Open HR Diagram mode.

  1. Have one image of a star field ready. A plate-solved image already records where its pixels fall on the sky. The example uses a color-calibrated RGB image of M46 with that information embedded.
  2. Allow internet access for a fresh Gaia catalog lookup. Click OK (1) to continue.
What you should see

The left side of the workspace offers Open. The diagram fills after CAst matches stars in the selected image.

Choose an image →Match the example’s source limit → Browse all steps

Open the M46 image / Step 03

Find the Open button

Start here You are in the HR Diagram workspace.

  1. Click Open (1) at the upper left. The keyboard shortcut is Ctrl+O.
What you should see

A file picker titled Select solved RGB source image opens. It takes one image at a time.

Select M46.xisf → Browse all steps

Open the M46 image / Step 04

Open M46.xisf and build the diagram

Start here The file picker is open. Use your copy of the example, or substitute a plate-solved image of your own.

  1. Go to the extracted M46 folder and select M46.xisf. You can also type its full path in the file-name box (1).
  2. Click Open (2). Give CAst time to load the image, find stars, look up Gaia matches and measure them. The preparation button reads Generating... while it works.
What you should see

The star field appears on the left and colored points fill the diagram on the right. These screenshots use the saved catalog and 10,000 measured rows for this M46 image. Your source limit and catalog coverage can change the number of points. To match the example’s measurement limit, set HR Max Sources to 10000 before opening the file.

Read the axes →Inspect a single star →Choose part of the image →Find stars moving together → Browse all steps

Open the M46 image / Step 05

Open the measurement settings

Start here You are in the HR Diagram workspace. This optional branch reproduces the image-source limit used for the M46 screenshots.

  1. In the main menu, click Settings (1), then Open Settings (2).
What you should see

The application settings window opens with tabs for the different workspaces.

Set the example’s source limit →Use the current settings → Browse all steps

Open the M46 image / Step 06

Set how many matched stars CAst measures

Start here Open Settings.

  1. Click the HR Diagram tab (1). Click the HR Max Sources field (2), select its contents, and enter 10000 for the M46 example. The default of 5000 gives a shorter first run.
  2. Click Save (3), then open the image. If the image is already on screen, reopen it to run preparation with the new limit.
What you should see

CAst measures up to the chosen number of matched sources, starting with the brightest detections. The field catalog can contain more stars than the working table. The table and plot can also show fewer rows after filtering.

Open M46 with these settings → Browse all steps

Read the stars / Step 07

Read the color and brightness scales

Start here Open an image and wait for the diagram. Use the default Gaia axes.

  1. Read the bottom scale (1) from left to right. Stars go from hotter and bluer to cooler and redder. The values in kelvin are estimates from the Gaia color index BP−RP shown along the top.
  2. Read the left scale (2) from bottom to top. Higher points represent brighter stars on this luminosity scale. The right scale gives Gaia absolute G magnitude, the brightness a star would have at a common distance. Smaller magnitudes are brighter.
What you should see

A band of stars runs from the upper left toward the lower right. Each point represents a measured star matched to Gaia. The field includes foreground and background stars along the same line of sight.

Identify one of these points →Read the stellar class guides →Look for candidate cluster members →Save the diagram → Browse all steps

Read the stars / Step 08

Choose a star on the plot

Start here The diagram shows colored points.

  1. Click one colored point. The small box (1) marks an orange point used in this example. You can choose any visible point in your own field.
What you should see

CAst circles the selected point, opens its information card and highlights the corresponding source in the image. The example star is APASS J074114.1-145208.1.

Read the star’s measurements →Locate it in the table → Browse all steps

Read the stars / Step 09

Connect the plot point to the photograph

Start here Select a point. If the table is open, click Image to see the photograph.

  1. Read the selected star’s name, Gaia G magnitude and BP−RP color in its plot card. The orange example star has G = 11.58 and BP−RP = 1.55. Find the selection circle in the source image to see which star produced that point.
  2. Click Results (1) to inspect its table entry. To try the reverse direction later, switch back to Image and double-click a measured star in the photograph.
What you should see

The left panel switches to Source Results and Work Log, while the diagram and its star selection remain on the right.

Read the selected table row →Choose a region on the image → Browse all steps

Read the stars / Step 10

Inspect a measurement in Source Results

Start here Click Results with an individual star selected.

  1. Find the highlighted row (1). Click a different row to select another star. Scroll across the table for its Gaia magnitude, color, parallax and measured quantities.
  2. Read the Work Log under the table for the source filename, catalog totals and processing notes. Click Image (2) to return to the photograph.
What you should see

The selection follows the row you clicked. The Work Log records the full preparation run even when a filter narrows the visible stars.

Select a star in the plot →Limit the plotted population →Save the plotted measurements → Browse all steps

Read the stars / Step 11

Compare stars with the stellar class guides

Start here The M46 diagram is visible.

  1. Find Class Guides (1) above the plot. If it is already checked, click it once to hide the dashed lines and again to restore them.
  2. Follow the line labeled Main Sequence through the diagonal band. Look above the band toward Giants to find stars that appear bright for their color.
What you should see

The labeled guide curves appear and disappear over the same measured stars. They indicate approximate regions where different kinds of stars tend to sit.

Explore the age guide →Inspect a star near a guide → Browse all steps

Read the stars / Step 12

Move the illustrative age guide

Start here Open the diagram with its default axes.

  1. Check Age Guide (1). Click the adjacent age field (2), enter 1.0 and press Enter. One Gyr is one billion years.
  2. Try a larger value and watch where the curve bends away from the main sequence. Clear Age Guide to hide the curve.
What you should see

Changing the age moves the guide while the measured points stay in place. The displayed age is the value you chose for comparison. Determining M46’s age requires additional analysis.

View stellar class guides →Compare a subset of stars →Export the plot → Browse all steps

Choose which stars to compare / Step 13

Draw and apply a circular region

Start here Load the M46 image and click Image. Use the default Circle ROI tool. ROI means region of interest.

  1. Hold Shift. Press the left mouse button near the center of the cluster (1) and drag outward to the desired edge (2). Release the mouse button, then release Shift.
  2. Check the shaded circle on the photograph. Click Update (3) to apply it. To redraw, make a fresh Shift-drag before clicking Update.
What you should see

The diagram and table now use the measured stars inside the circle. Update changes to Reset after the draft has been applied.

Bring back the full field →Search this region for shared motion →Save the regional diagram → Browse all steps

Choose which stars to compare / Step 14

Restore all parts of the image

Start here An applied region is visible on the photograph.

  1. Find Reset (1) at the upper left, beside Open. The region summary at the bottom right (2) tells you which part of the field currently contributes stars.
  2. Click the upper-left Reset (1) to clear your applied region. The separate Reset button above the chart restores the plot view.
What you should see

The circle disappears, the diagram uses the full image again and the upper-left button returns to Update. Other active plot filters still apply.

Draw another circle →Search the entire field →Filter by another property → Browse all steps

Choose which stars to compare / Step 15

Find stars that move together

Start here Start with the measured field or an applied region.

  1. If you want to see arrows on the source image, click Show Motion (1). They show the direction of each star’s cataloged motion across the sky.
  2. Click Find Cluster (2). CAst compares Gaia proper motions and, when available and enabled, parallaxes to find a group with similar motion.
What you should see

The group is highlighted, Find Cluster changes to Find All, and Only Group becomes available. If no group is found, try drawing a smaller region around the cluster and repeat.

Isolate the candidate group →Narrow the search area → Browse all steps

Choose which stars to compare / Step 16

Isolate or clear the candidate group

Start here Find Cluster has returned a group.

  1. Check Only Group (1) to restrict the diagram, table and arrows to the highlighted candidates. Clear the checkbox to see them in context with the other stars.
  2. Click Find All (2) to clear the group selection. If you turned on motion arrows, click Hide Motion when you are finished with them.
What you should see

Only Group narrows the diagram to stars that passed the chosen motion criteria. Similar motion is evidence for membership. Some unrelated field stars can satisfy the same criteria.

Explore a distance interval →Save the selected population →Inspect candidate rows →Explore candidate motions in Distance Map → Browse all steps

Choose which stars to compare / Step 17

Open the star filter

Start here Generate the diagram. To compare the entire field, clear any region or group first.

  1. Click Filter... (1) above the diagram. When a filter is active, the button says Filter On.
What you should see

The Filter stars dialog offers separate switches for color and temperature, distance, luminosity, and stellar class. A switch expands its controls when turned on.

Try a distance interval →Remove existing limits → Browse all steps

Choose which stars to compare / Step 18

Keep stars in a distance interval

Start here Open Filter stars.

  1. Turn the Distance switch on (1). Enter 1000 in the From field (2) and 2000 in the to field (3). The unit pc means parsecs.
  2. Click Apply (4). These distances are estimated from Gaia parallax, the small shift in a star’s position as Earth orbits the Sun.
What you should see

The diagram and table keep stars with usable parallaxes whose estimated distances fall in the interval. The toolbar says Filter On. Stars at similar distances can also belong to unrelated populations.

Clear the distance selection →Read the retained measurements →Save the filtered plot → Browse all steps

Choose which stars to compare / Step 19

Clear all star-filter switches

Start here Click Filter On above the diagram to reopen the filter dialog.

  1. Click Turn all off (1) in the lower left. Click Apply (2) to return to the diagram.
What you should see

The toolbar returns to Filter... and the star-filter limits are removed. An applied image region or Only Group selection can still narrow the plot.

Clear an applied region →Clear a motion selection →Read the full diagram → Browse all steps

Save a figure or a table / Step 20

Export a scientific figure

Start here A measured diagram is on screen. Choose the region and filters you want to include first.

  1. Click Export (1) at the upper right of the plot. Choose Scientific (2) to save a clean scientific figure.
  2. For a figure styled like the current chart, choose Snapshot from the same menu.
What you should see

A Save dialog opens. The scientific plot export uses the currently selected population.

Name and save the figure →Save the image with the plot →Save the measurements as well → Browse all steps

Save a figure or a table / Step 21

Export the image and diagram together

Start here Open M46 and select the image view and plotted population you want to show.

  1. Click plot Export (1), then Image + Plot... (2) to make a paired PNG. To keep only the annotated photograph, choose Source Image... in the same menu.
What you should see

A Save dialog opens for your PNG. The paired figure includes both the current source-image view and the chart.

Choose the output file →Keep a scientific plot and table too → Browse all steps

Save a figure or a table / Step 22

Name and save the figure

Start here A Save dialog is open from Scientific, Snapshot or Image + Plot.

  1. Choose an output folder you can find again. Enter a new filename (1), such as M46-diagram.png when the file type is PNG.
  2. Click Save (2). Open the file in the output folder to inspect the figure.
What you should see

The saved figure is available outside CAst. For a table of the plotted measurements, use the File menu export.

Export the plotted measurements →Make a figure for another region → Browse all steps

Save a figure or a table / Step 23

Export the science table and both figures

Start here A diagram with plotted stars is open. Apply any region or filters that you want reflected in the output.

  1. Open File (1) in the main menu. Click Export (2) in that menu to start the HR science bundle.
What you should see

CAst asks for a folder. The bundle contains an annotated source image, a scientific HR diagram and a CSV with rows for the plotted stars.

Choose the destination folder →Save only the diagram → Browse all steps

Save a figure or a table / Step 24

Choose a folder for the bundle

Start here The folder picker opened from File → Export.

  1. Navigate to your desired parent directory. You can enter its path in the folder field (1).
  2. Click Choose (2). The native Windows folder picker may label this button Select Folder.
What you should see

A small Export Name dialog appears. CAst will create a named subfolder within the directory you selected.

Name the bundle → Browse all steps

Save a figure or a table / Step 25

Name and inspect the three output files

Start here Choose a destination folder.

  1. Type a new name such as M46-stars in the export-name field (1). Click OK (2).
  2. Open the new M46-stars subfolder. Open the file ending in _science_table.csv in a spreadsheet to inspect the plotted stars.
What you should see

For the example PNG settings, the folder contains M46-stars_source_image.png, M46-stars_hr_diagram.png and M46-stars_science_table.csv. With the full image and default plot settings, this M46 export contains 9,704 plotted rows from the 10,000 measured stars. The Work Log records the export.

Export a different selection →Return to an individual star → Browse all steps
