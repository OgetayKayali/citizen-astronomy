Generate a light curve / Step 05

Start the measurement

Start here The folder scan has found 24 practice images or 158 full-sequence images.

  1. For this L-filter practice run, clear Pull Periods (1). Leave Calculate Periods, Create Measurements Table, Calibration, and Star Alignment unchecked. The folder contains science exposures with embedded sky coordinates and includes no calibration masters.
  2. Keep Brightest Variables at 100% so you can choose AE UMa yourself. Click Generate (2). Allow the catalog lookup to finish. A first run can need internet access.
What you should see

CAst opens Select Sources To Process when the list is ready. If CAst offers an existing result for this folder, opening it takes you directly to the results. The example used a saved field catalog and the images’ embedded coordinates. See the example settings to reproduce this selection.

Measure AE UMa only →Check the example settings →Measure a group of stars →I opened a saved result → Browse all steps

Generate a light curve / Step 06

Check how the example was measured

Start here In the Differential Photometry workspace, choose Settings → Open Settings before starting a fresh run.

  1. Click the Differential Photometry tab (1). The example requested 5 for Comparison Stars per Variable (2). The number that can actually be used depends on the stars in the field.
  2. To match the brightness selection, check Use reference-star magnitude range. Set Min to the lowest allowed value (−5) and Max (3) to 16. The adaptive aperture scale was 1.60 × FWHM, which sizes the measurement circle using the width of the star image.
  3. Click Save if you changed settings, or Cancel if you were only looking. This example used the saved catalog for the field and the embedded sky coordinates in each FITS header, without repeating the Gaia cross-check.
What you should see

The resulting Scan Comps window offered four usable measured references. Catalog updates or different quality settings may change the available stars.

Continue the example run →Inspect the measured references → Browse all steps

Generate a light curve / Step 07

Measure AE UMa only

Start here The source-selection window is open.

  1. In the Sources search field (1), type AE UMa. Keep Named variables checked.
  2. Click the AE UMa row (2). Its catalog is vsx and its type is Variable. CAst chooses comparison stars for the target automatically.
  3. Click Process Selected (3). Wait for the workflow to finish measuring the images. If its progress window stays open after completion, click Close.
What you should see

The Source Results table contains AE UMa. A light curve is a sequence of brightness measurements, one for each usable exposure.

Find the measured star →What do the other process buttons do? → Browse all steps

Generate a light curve / Step 08

Measure several objects instead

Start here Open the source-selection window before processing.

  1. To measure the brightest few, set Default selection to Absolute number of brightest stars and enter a small count, such as 3 (1). Click Process Default (2).
  2. To work by category instead, choose a category from All types (3) and narrow the list with Sources or Designation Families. Click Process All Visible (4) to measure every remaining row. A long list takes longer.
What you should see

After processing, Source Results lists the measured targets. Click a row to switch the light curve to that star.

Return to the one-star example →Inspect a completed run → Browse all steps

Read and check the result / Step 09

Select the measured star

Start here The reduction has finished, or you opened a cached AE UMa result.

  1. Click Source Results (1) below the plot.
  2. Click AE UMa (2). The workspace connects the selected source to its light curve and image. Other rows can be comparison stars used to measure the target.
What you should see

Look for AE UMa in the plot title or legend. A blank graph in Standard Magnitude can mean that this filter has no usable standard magnitude. Choose the relative brightness axis in the next step.

Plot brightness relative to the comparisons →Inspect the original exposures →Open individual measurements → Browse all steps

Read and check the result / Step 10

Switch to differential magnitude

Start here You have selected AE UMa.

  1. Open Settings (1) on the top menu bar, then move to Light Curve (2).
  2. Open the Y list (3) and choose Differential Magnitude. Click outside the menu to return to the graph.
What you should see

The vertical axis now shows magnitude relative to the comparison stars. A smaller value means a brighter target relative to them. On the plotted axis, 500 × 0.001 means 0.500 magnitude. These L-filter frames can show changes in brightness without establishing a standard Johnson V magnitude.

Compare the target with reference stars →Save the current graph → Browse all steps

Read and check the result / Step 11

Compare the star with its references

Start here AE UMa is selected. Use the differential magnitude axis.

  1. Open the Filter list (1) beside Open and choose L for this sequence.
  2. Turn on Show references (2) to display the comparison stars. If their traces move together with the target, inspect the images for clouds or tracking problems.
  3. Turn on Show check (3) to include an independent check star when one was measured. For a clearer view of AE UMa alone, clear both switches.
What you should see

AE UMa brightens toward the end of the run while the comparison traces remain relatively flat. The practice download provides 24 epochs. The screenshot shows measurements from all 158 original exposures.

Try a different set of comparison stars →Keep the automatic set and inspect the images →Trace a point to its exposure →Save a picture of the curve → Browse all steps

Read and check the result / Step 12

Inspect a single frame or blink the sequence

Start here A measured target is selected and its image is visible on the right.

  1. Click Center (1) to bring the selected star into view. Use the mouse wheel over the star if you want a closer look. The small circle is its measurement aperture.
  2. To inspect one exposure, open the frame selector (2) and choose a filename. Watch whether the aperture still encloses AE UMa.
  3. To play the sequence, click Blink (3). Click Blink again to pause. Look for shifts, passing clouds, or a neighboring star entering an aperture.
What you should see

Changing the frame changes the filename and image. Use the measurement table to identify the exposure time and brightness for an individual observation.

Open the numerical measurements →Compare plotted stars → Browse all steps

Start here The Scan Comps window is on 1. Limits.

The window moves to 2. Favourites and lists measured stars with their names, catalog brightness, and distance from AE UMa.

Try other comparison stars / Step 19

Choose which reference stars to test

Start here You have built candidates and 2. Favourites is visible.

  1. For this small example, click Select All (1). If you saw a blended or unstable reference on the images, clear its Favourite box. Keep at least three to build a set; four or more give you alternative three-star sets.
  2. Click Continue to Combinations (2).
What you should see

The next page lists the possible three-star sets and calculates a preview for each.

Compare the trial curves →Change the pool size or limits → Browse all steps

Try other comparison stars / Step 20

Compare trial curves and apply a set

Start here The Favourites step has opened 3. Combinations.

  1. Click a set in Combination Sets (1). Inspect the light curve, then click another set to see whether the pattern persists.
  2. Use the preview list (2) to switch between Filter [L] and Overview (with comps). Look for stable comparisons and a target trend that survives a change of reference stars.
  3. Choose Use Selected (3) to apply the displayed set. Choose Cancel if you want to keep your previous result.
What you should see

Applying a set updates the AE UMa curve for the L filter. The Work Log identifies the comparisons used.

  2. Choose Export Report (2).

Save the graph or the measurements / Step 24

Review the report before saving

Start here You have opened File → Export Report for AE UMa.

  1. Read Rows ready for AAVSO export, Skipped measurements, and Warnings. Here 150 rows are ready for the export file and 8 were skipped. CAst lists an unmapped L filter, missing airmass, and a blank observer code. The Standard rows count alone cannot establish a Johnson V magnitude from these L frames.
  2. Choose Cancel (1) if you need to correct the setup or revisit the reduction. To keep a local practice report after reading the warnings, click Export Anyway (2).
  3. After export finishes, open the science folder beside the input images, then AE_UMa. Open AE_UMa_measurements.csv for the numbers. AE_UMa_accepted_observations.csv, AE_UMa_rejected_observations.csv, and AE_UMa_aavso_preflight.json document the export decisions.
What you should see

The Work Log records the export paths. Saving this bundle is a local operation. Review the warnings and scientific suitability separately before submitting any observation.

Review individual rows →Save a display figure → Browse all steps
